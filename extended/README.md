# Extended Custom Module Architecture & Git Commit Rules

This directory contains custom extensions for **MoneyPrinterTurbo** designed to maintain clean separation from upstream repository updates.

## Directory Structure
- `extended/tempo_controller.py`: Custom logic for dynamic video clip duration & AI tempo control.
- `extended/GIT_CONVENTION.md`: Git commit rules for custom development.

## Git Commit Rules
When committing custom changes:
- `feat(extended): ...` - New custom features (e.g. `feat(extended): add AI dynamic tempo control`)
- `fix(extended): ...` - Custom feature fixes
- `refactor(extended): ...` - Refactoring extended modules
